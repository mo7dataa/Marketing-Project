# Marketing Campaign Analysis Dashboard

## Project Overview
This project focuses on analyzing marketing campaign performance using Python and an interactive dashboard.  
The analysis was conducted on a marketing dataset to discover insights about campaign effectiveness, customer engagement, conversions, and return on investment (ROI).

The project includes:
- Raw Dataset (Before Cleaning)
- Cleaned Dataset (After Preprocessing)
- Data Analysis Notebook
- Interactive Dashboard

---

# Objectives
- Analyze marketing campaign performance
- Measure engagement and conversion rates
- Identify the most effective campaign channels
- Calculate ROI and campaign efficiency
- Build an interactive dashboard for visualization

---

# Dataset
The dataset contains marketing campaign information such as:
- Impressions
- Clicks
- Leads
- Conversions
- Revenue
- Acquisition Cost
- Campaign Type
- Target Audience
- Channel Used
- Engagement Score
- Duration
- Date

### Dataset Versions
- Before Cleaning: Raw dataset with original values
- After Cleaning: Processed dataset after feature engineering and validation

---

# Data Cleaning & Preprocessing
The following preprocessing steps were applied:
- Handling missing and invalid values
- Converting date columns
- Creating new KPIs and calculated metrics
- Validating campaign funnel logic
- Removing duplicated and unnecessary columns
- Formatting and rounding numerical values

### New Features Created
- Click-through Rate (CTR)
- Lead Conversion Rate
- Conversion per Lead
- Conversion per Click
- ROI Validation Metric

---

# Technologies Used
- Python
- Pandas

- Plotly
- Google Colab
- Power BI / Dashboard Tools

---

# Dashboard Features
The dashboard provides:
- Campaign performance overview
- Revenue and ROI analysis
- Conversion funnel analysis
- Channel performance comparison
- Engagement tracking
- Time-based campaign trends

---

# Project Files
- marketing_analysis.ipynb → Analysis notebook
- raw_dataset.csv → Dataset before cleaning
- campaigns.csv → Cleaned dataset
- dashboard.pbix / dashboard screenshots → Dashboard files

---

# Key Insights
- Some marketing channels generated higher conversion rates than others.
- ROI varied significantly across campaign types.
- Engagement score showed a strong relationship with conversions.
- Campaign duration affected overall performance.

---

# How to Run the Project
1. Open the notebook in Google Colab or Jupyter Notebook
2. Upload the dataset
3. Run all notebook cells
4. Explore the generated cleaned dataset and dashboard
